MariaDB 샘플 데이터 생성, VectorDB 문서 적재, 질문 답변 실행까지 3단계 흐름으로 구성된 프로젝트

구성은 이렇게 되어 있습니다.

edu_ai_chatbot_langchain_mariadb_chroma/
├─ app/
│  ├─ config.py          # .env 설정 읽기
│  ├─ db.py              # MariaDB 조회
│  ├─ vector_store.py    # Chroma VectorDB 적재/검색
│  ├─ prompts.py         # LangChain Prompt
│  └─ chatbot.py         # 질문 분석 → DB 조회 → 문서 검색 → 답변 생성
│
├─ scripts/
│  ├─ 01_seed_mariadb.py # MariaDB 샘플 데이터 생성
│  ├─ 02_ingest_docs.py  # 문서를 VectorDB에 적재
│  └─ 03_run_chatbot.py  # 챗봇 실행
│
├─ sample_docs/
│  ├─ completion_policy.txt
│  ├─ operation_plan.txt
│  ├─ job_support.txt
│  └─ notice.txt
│
├─ requirements.txt
├─ .env.example
└─ README.md

사용 기술은 다음 기준으로 맞췄습니다. LangChain은 LLM 애플리케이션과 에이전트를 구성하기 위한 프레임워크이고, OpenAI 연동은 langchain-openai의 ChatOpenAI, OpenAIEmbeddings를 사용하도록 구성했습니다.
VectorDB는 교육용으로 가장 다루기 쉬운 Chroma를 사용했고, LangChain 공식 문서 기준으로 langchain-chroma 통합 패키지를 사용했습니다.

실행 순서는 README에도 넣어두었습니다.

pip install -r requirements.txt
copy .env.example .env
python scripts/01_seed_mariadb.py
python scripts/02_ingest_docs.py
python scripts/03_run_chatbot.py

예시 질문은 이런 식입니다.

홍길동 교육생은 현재 수료 가능성이 있나요?
김민수 교육생은 출석률 때문에 문제가 있나요?
이영희 교육생에게 취업지원은 어떻게 안내하면 좋나요?

코드는 일부러 현업형에 가깝게 구성했습니다.
LLM이 SQL을 직접 생성해서 실행하는 방식이 아니라, 파이썬 코드가 안전한 SELECT 쿼리만 실행하고, LLM은 조회 결과와 문서 검색 결과를 바탕으로 답변만 생성하게 했습니다.
